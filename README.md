# 🔮 inastralium

Интерактивная Fullstack-платформа с интеграцией ИИ, созданная как **воронка продаж (lead generation)** для эзотерических услуг. 

Пользователь вводит свои данные, получает бесплатный мини-разбор (главный аркан и Таро-прогноз), а затем вовлекается в покупку полной консультации через Telegram-бота.

🌐 **[Посмотреть живой сайт](https://inastralium.pages.dev/)**

## 🚀 Технологический стек

*   **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS, Handlebars (шаблонизатор для переиспользования компонентов).
*   **Сборка:** Vite (многостраничная сборка).
*   **Backend / Serverless:** Cloudflare Pages & Functions (Node.js).
*   **AI:** Groq API (модель Llama 3).
*   **Деплой:** Cloudflare Pages (CI/CD из GitHub).

## ✨ Ключевые особенности реализации

*   **Безопасный бэкенд:** Интеграция с ИИ вынесена на серверные функции Cloudflare (`/api/ai`). API-ключи надежно скрыты от пользователя и не хранятся в клиентском коде.
*   **Приватность:** Персональные данные (имя, дата, город) передаются между страницами через `sessionStorage`. Это исключает их попадание в URL, историю браузера, логи сервера и заголовки `Referer`.
*   **Строгая валидация:** Проверка возраста (18+), регулярные выражения для имени, проверка существования города через внешний API (Open-Meteo), блокировка отправки без согласия на обработку данных.
*   **Отказоустойчивость:** Реализованы скелетоны загрузки (skeleton screens). Если ИИ не отвечает — выводится понятное сообщение с кнопкой «Обновить». Прямой вход на дашборд без данных перенаправляет на главную.
*   **Доступность (A11y):** Ловушка фокуса (focus trap) в модальных окнах, корректные ARIA-атрибуты для мобильного меню и кнопок-бургеров.
*   **Умная логика:** Генерация карт Таро по сиду (карта не меняется при перезагрузке страницы), расчет матрицы судьбы по дате рождения.
*   **UI/UX:** Mobile-first, глубокий темный дизайн с золотыми акцентами, параллакс-эффекты, кастомный скролл-слайдер на главной странице.

## 📦 Развертывание

Проект настроен на автоматический деплой через Cloudflare Pages. 

Для локальной разработки:
1. `npm install`
2. `npm run dev`
3. Для тестирования серверных функций локально используется `npx wrangler pages dev dist` (потребуется файл `.dev.vars` с ключом `GROQ_API_KEY`).
